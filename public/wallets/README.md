# Wallet icons for Connect Wallet modal

Place wallet icon images here. Filenames must match wallet `id` (lowercase).

**Expected files (`.svg` or `.png`):**

- `browser.svg` or `browser.png`
- `metamask.svg` or `metamask.png`
- `okx.svg` or `okx.png`
- `ledger.svg` or `ledger.png`
- `walletconnect.svg` or `walletconnect.png`
- `bitget.svg` or `bitget.png`
- `imtoken.svg` or `imtoken.png`
- `ambire.svg` or `ambire.png`
- `coinbase.svg` or `coinbase.png`

The modal tries `.svg` first, then `.png`. If neither exists, the first letter of the wallet name is shown. Recommended size: 32×32 px or 64×64 px (they are displayed at 32×32).
